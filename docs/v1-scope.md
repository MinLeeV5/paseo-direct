# Paseo Direct 1.0

将已通过 Android 往返切换验证的原型整理为可安装、可配置、可维护的插件。

- 手机默认在前台自动探测，桌面和 Web 默认只观察；每个客户端、每台 PC 的开关、选路偏好、检测间隔、语言和 relay 暂停时间独立保存。
- PC 通过官方插件设置保存自动发现开关、忽略的网卡与自定义地址；支持显式 TLS 地址，所有候选均核对现有 PC 身份。
- 提供直连优先和遵循 Paseo 默认选路两种行为；保留 relay，避免反复切换，不覆盖人工维护的连接参数。
- 记录由插件新增的地址，允许用户移除非活动地址；后台不自动删除连接。
- 失败可重试，进入后台或卸载时取消工作，旧安装不能提交迟到的结果；已交给 App 的连接不由插件关闭。
- 日常页面显示连接和设备设置；PC 设置、候选与诊断详情分层呈现，支持中文与英文。诊断上报改为主动发送。
- 提供 1.0 分发包、发布说明、CI、许可证和中英文 listing，验证干净安装、设置持久化和回归。

支持 Paseo 0.13.0 及以上版本，不设版本上限；运行时检查所需的私有连接接口，接口缺失时停止操作。后台常驻、首次完全离线发现和 IPv6 网卡自动发现不作保证。公开发布渠道独立于本次本地实现和升级。

界面沿用 Paseo 的主题 token、原生字体和设置组件。主要视觉元素是一条当前连接状态行；避免把验收检查表留在日常首页。窄屏按内容自然换行，详细记录按需展开。
